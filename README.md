# MSOT Quest — Learn & Level Up

## Project description
MSOT Quest is a gamified learning website prototype. It includes a home page, a progress dashboard, a daily multiple-choice quiz, demo XP rewards, badges, a practice task, and a sample leaderboard.

## Tech stack
- HTML
- CSS
- JavaScript
- Browser `localStorage` for saving demo progress
- Visual Studio Code

## Features
- Navigation between Home, Dashboard, Daily Quiz, and Leaderboard
- Dashboard for XP, level, streak, and badges
- Three-question daily quiz
- XP rewards for quiz completion and practice
- Achievement badges
- Sample leaderboard
- Responsive layout for smaller screens

## How to run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or open the project folder in Visual Studio Code and use Live Server.
3. Use the navigation buttons to explore the pages.

## Current status
This is a frontend demonstration/prototype. It does not currently have a backend, database, user authentication, or a real shared leaderboard. Progress is stored in the current browser using `localStorage`.

## Future improvements
- Add user registration and login
- Store progress in a database
- Connect a real leaderboard
- Add more quiz categories and questions
- Deploy the website publicly
